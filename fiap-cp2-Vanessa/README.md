# Checkpoint 2 — Passo Alto

HTML do Checkpoint 2 de Frontend Design (FIAP, turma 2).

## Como usar

1. Baixe o projeto: botão verde **Code → Download ZIP**.
2. Crie o arquivo `styles.css` na mesma pasta do `index.html`. O HTML já aponta para ele.
3. Escreva o CSS até a página ficar igual ao seu frame no [Figma](https://www.figma.com/design/4iQfByDpCegSpNHw0OeF7u).

Paleta, fontes, ordem das seções, critérios e um snippet de partida estão em [dicas.md](dicas.md).

**Não altere o `index.html`.** As instruções completas estão na tarefa do Teams.
